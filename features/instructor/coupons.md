# Coupons

This section is divided into two sub-sections:

![Coupons List](../../static/images/web/coupon_list.png)

- **All Coupons** – Lists existing coupons on the instructor profile with edit and delete options.

![Add New Coupon](../../static/images/web/coupon.png)

- **Add New Coupon** – Allows creating new coupons with the same fields available in the admin panel. The distinction is that instructor coupons can only be applied when purchasing a single course directly, not when purchasing through the cart.
