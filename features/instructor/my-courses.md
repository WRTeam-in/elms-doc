# My Courses

![My Courses](../../static/images/web/my_courses.png)

The My Courses page allows instructors and team instructors to manage all their created courses from a single place. It provides course statistics, management actions, and a detailed listing of all courses.

### Course Overview

Displays course counts grouped by their current status: Active, Pending Approval, Rejected, and Draft.

### Course Listing

Displays all instructor courses with details such as course title, category, chapter count, pricing, enrollments, and status. Each course in the listing includes action options to view **Course Details** and **Edit** the course.

The **Course Details** page provides complete course information and management tabs, including:

- **Course Statistics** – Earnings, enrollments, ratings, sales statistics, and overall performance data.
- **Course Details** – Pricing, instructor details, duration, level, and access type.
- **Students Enrolled** – A list of enrolled students with their enrollment details.
- **Assignments List** – Assignment tracking for the course.
- **Quiz Report** – Quiz performance and attempt data.
- **Discussion** – Course discussion thread management.
- **Reviews** – Student reviews submitted for the course.

The **Edit** option opens the same course creation form, allowing instructors to update existing course details and content.

### Search & Filters

Search and filtering options are available to quickly find and manage courses based on different criteria.

### Add Course

The **Add Course** button allows instructors to create and submit new courses to the platform.

Courses can be added with the following details:

**Course Details:**
- Title, Description, Category (dynamic selection), Difficulty (one of 3 levels), Language Mode (dynamic selection), Course Tags (dynamic selection with creation option), What You'll Learn points, Requirements points, Meta Tag, Meta Title, Meta Description, Course Thumbnail Image, Course Preview Video, and Sequential Completion toggle.

**Pricing:**
- Free or paid, with Price and Discount Price fields in the system currency.

### Curriculum & Content

Chapters can be created within this section with a sequence change option. Each chapter has a name that can be edited or deleted. Within each chapter, the following four curriculum item types can be added:

**Lecture** – Includes a title, type (YouTube or file upload), duration (hours, minutes, seconds), file or YouTube URL, a toggle for whether the lecture is a free preview (watchable before enrollment), and Resource Management (type, title, and file — supports Image, Audio, Video, External URL, and Document).

**Quiz** – Includes a title, total points, and pass grade, with an option to enable or disable quiz skipping. Questions are added with radio button-type options, where only one answer can be marked as correct. Total marks are equally distributed across all questions. After passing a quiz once, further attempts are not counted.

**Assignment** – Includes a title, description, optional media file, allowed submission types (Image, Video, Audio, Document — multi-select), points, and a skippable toggle.

**Resource** – Similar to lecture resources, with a title, type (Image, Audio, Video, External URL, or Document), description, file or URL, and an optional duration in seconds.

**Certificate Publish Option** – When publishing, there is an option to add a certificate unlock amount. A toggle allows the certificate to be either free after course completion or require an additional payment to obtain — this option is only available for free courses.

### Course Review

Each newly submitted course is sent to the admin for approval and appears under Course Publish Requests in the admin panel, where it can be approved or declined.

### Team Course

Co-instructors can be selected while creating a new course in team mode. If no co-instructors have been added to the team yet, they can also be invited directly from this screen. All co-instructors of a course can manage its details and discussions together.
