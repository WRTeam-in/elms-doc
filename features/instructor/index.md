# Instructor Features

This section covers all features available to instructors managing courses, earnings, assignments, and student interactions through the instructor web portal.

## Feature Pages

| Feature | Description |
|---------|-------------|
| [Dashboard](./dashboard) | Overview of courses, earnings, student engagement, and platform activity for the instructor account. |
| [Instructor Profile](./profile) | Set up and manage instructor profile; convert a user account using the Become an Instructor flow. |
| [My Courses](./my-courses) | View and manage all created courses, course statistics, and course-level actions from one place. |
| [Live Classes](./live-class) | Schedule, conduct, and manage live interactive class sessions with external meeting links and student analytics. |
| [Team Members](./team-members) | Invite co-instructors by email and manage the team roster; all earnings remain with the course owner. |
| [Assignments](./assignments) | Review student assignment submissions across all courses and set acceptance, rejection, or suspension status. |
| [Reviews](./reviews) | View student reviews on the instructor profile with average rating and star-wise breakdown. |
| [Coupons](./coupons) | Create and manage instructor-level coupons applicable to single-course direct purchases. |
| [Earnings](./earnings) | Revenue overview, commission breakdown, earnings graph, and payout request management. |
| [Notifications](./notifications) | Full notification history covering enrollments, submissions, refunds, course approvals, and reviews. |
| [Teams](./teams) | View and switch between team accounts where the instructor has been added as a co-instructor. |
| [Header Options](./header-options) | Quick access to notifications, account settings, and sidebar toggle from any page in the panel. |
