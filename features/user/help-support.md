# Help & Support

Users can access the Help & Support section to explore FAQs, search support topics, and participate in community discussions

- **Community Groups** – Users can browse groups, ask questions, post discussions, reply to others, and interact with the community. Groups can be public or private. Private groups require a join request before participation is permitted.

![Help & Support](/images/features/user/help-and-support.png)

- **Discussions** – Users can browse existing discussions, view replies and engagement details, and create new questions within available groups.

![Discussions](/images/features/user/discussions.png)

- **FAQs** – Available for quick access to common queries and support information.

![FAQ](/images/features/user/faq.png)
