# Course Learning

Users can access the learning page after enrolling in a course. The learning page includes the course player, progress tracking, and the following tabs:

- **Overview** – Displays course details, description, learning outcomes, requirements, instructor details, and course information such as chapters, lectures, duration, level, language, and certificate availability.
- **Resources** – Allows users to access chapter-level and lecture-level downloadable files.
- **Discussion** – Enables learners to ask questions, reply to discussions, and interact with other learners and the instructor.
- **Assignment** – Shows assignment details, the user's submissions, instructor feedback, and approval status.
- **Reviews** – Displays course ratings and allows enrolled users to submit a review.
- **Certificate** – Tracks completion requirements and allows certificate download once all conditions are met. Free courses can optionally have paid certificates.
