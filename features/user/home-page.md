# Home Page

The home page of the application and website showcases the following content:

- **Banners** – Admin-configured slider images displayed at the top.
- **Categories** – Shown with their course count; tapping a category opens the courses listed under it.
- **Featured Sections** – Different featured sections enabled from the admin panel are displayed with their course or instructor cards.
- **Offer Image** – An image that the admin adds as part of a featured section, displayed as a visual offer block.
