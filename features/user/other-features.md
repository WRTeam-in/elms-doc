# Other Features

- **Language Selection & RTL Support** – Users can change the application language from the available options. Right-to-left layout support is available for supported languages.

![Language Selection](/images/features/user/language-selections.png)

- **Notifications** – Users can view all notifications, with supported notifications allowing direct navigation to the related course details page.

![Notifications](/images/features/user/notifications.png)

- **Edit Profile** – Users can update their profile details and select their country, which is used for tax calculation during checkout.

![Edit Profile](/images/features/user/edit-profile.png)

- **Account Security** – Users can update their account password from the security settings.

![Account Security](/images/features/user/account-security.png)

- **Wishlist** – Users can view all wishlisted courses, remove courses from the wishlist, or add them directly to the cart if not already enrolled.

![My Wishlist](/images/features/user/my-wishlist.png)

- **Delete Account** – Users can permanently delete their account.

![Delete Account](/images/features/user/delete-account.png)

- **Logout** – Users can securely log out of their account.

![Logout](/images/features/user/logout-account.png)
