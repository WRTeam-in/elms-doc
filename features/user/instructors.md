# Instructors

In multi-instructor mode, the platform includes instructor listing and profile features for instructor discovery.

**Instructor Listing:**

- Supports category-based filtering.
- Each instructor card displays profile information, ratings, course count, and a preview video if the instructor has added one.

![Instructors Listing](/images/features/user/instructors-listing.png)

**Instructor Profile:**

- Displays biography, qualifications, skills, enrollment count, published courses, and instructor ratings and reviews.
- Students can add, edit, or delete their own reviews for instructors.

![Instructor Profile](/images/features/user/instructor-profile.png)
