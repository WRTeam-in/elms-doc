# Earnings & Transactions

### Orders

Displays order statistics — including total orders, pending orders, completed orders, and total revenue — along with an order list table with a view details option. Each order entry shows the Order ID, price, payment method, payment status, course details, and buyer details.

### Refund Requests

Lists all course refund requests along with statistics and filtering options. Each request can be viewed in detail, including the user's information, their past refund rate, course progress, and the reason for the refund request. It also includes the instructor's evaluation, which allows instructors to share their assessment of the refund. The admin makes the final decision to approve or reject the request with a note displayed to the user. Approved refund amounts are credited to the user's wallet and are both withdrawable and usable on the platform.

### In-App Purchase Products

eLMS provides in-app purchase product management to comply with App Store guidelines for digital purchases. Users can buy these packages to top up their wallet balance and use it to purchase courses instead of using a payment gateway. iOS wallet top-up products can be managed from this section. Each product entry supports a Product ID, credit value (the amount added to the wallet), description, and active or inactive status.

### In-App Purchase Transactions

Displays wallet top-up transactions made through in-app purchases, including the transaction ID and status, so the admin can track which users purchased which products.

### Taxes

System taxes are managed by the admin from this section. Each tax entry has a name and a percentage value. A tax can either be the default tax applied to every course purchase, or a country-specific tax that is applied based on the user's selected country during checkout.

### Promo Codes

System-level promo codes can be created and managed from this section. These codes apply to any courses as soon as their conditions are satisfied. Each promo code includes: a unique code, message, start date, end date, per-person usage limit (limited or unlimited), total usage limit (limited or unlimited), discount type (fixed amount or percentage), and discount amount. All available promo codes are shown to users during checkout. Codes auto-expire when the end date is reached and can also be manually deactivated by the admin at any time.
