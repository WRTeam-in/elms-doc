# Features

<DocBanner />

## Overview

This section outlines the core features currently implemented in eLMS and explains how they function within the system.

## Sections

The features are organised into three sections based on the type of user and their access level within the platform:

- **[Admin Panel Features](./admin-panel)** – Features available to administrators and authorised staff managing the platform through the centralised web-based admin panel.
- **[Instructor Features](./instructor)** – Features available to instructors managing courses, earnings, assignments, and student interactions through the instructor web portal.
- **[User Features](./user)** – Features available to students and learners accessing the platform through the mobile application and website.
