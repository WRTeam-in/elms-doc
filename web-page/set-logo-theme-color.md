# Basic Settings

To change the application name for your Web application:

1. Go to admin panel **settings -> system-settings**

![Web Title](/images/web/web-name.png)

To change favicon, logo, theme color, footer description, maintenance mode, system currency, schema etc.

1. Go to admin panel **settings -> system-settings**

![Favicon](/images/web/settings1.png)

![Favicon](/images/web/settings2.png)

# Set Favicon Icon

A favicon is a small icon that appears in browser tabs and bookmarks for your website.

1. You can generate favicon icons from this site: [Favicon Generator](https://www.favicon-generator.org/)

2. Go to admin panel **settings -> system-settings**

3. Upload your favicon icon

![Favicon](/images/web/favicon.png)
